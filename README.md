# Bangumi Friend Ratings Leaderboard

在 [bgm.tv](https://bgm.tv) 好友列表页生成好友评分排行榜的油猴脚本。

## 功能

- 在 `/user/*/friends` 页面统计好友评分，生成排行榜
- 使用 IndexedDB 本地缓存数据

## 安装

1. 安装用户脚本管理器（Tampermonkey / Violentmonkey）
2. 打开本仓库的 `Bangumi-Friend-Ratings-Leaderboard.user.js` 安装

## 支持站点

bangumi.tv / bgm.tv / chii.in
